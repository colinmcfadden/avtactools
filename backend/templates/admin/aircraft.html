How these are used

Spacing is derived as rotor diameter + tip clearance and drives the map footprint and separation alerts. Every profile seeds at the 60 m tip clearance the app has always used for the UH-60 — set the real per-platform figure on each profile.

Perf source says where the speed/fuel block came from. vidx was extracted from a real AMPS vehicle installation; published is a seeded starting point from public specs and should be verified before anyone plans fuel against it.

AMPS shows whether a real package is attached. Without one, MSNX export for that profile still produces a UH-60L mission file and warns the user — an airframe can't be synthesised without files AMPS produced.
